# andrewmish12.github.io

Andrew Mish's personal portfolio. Live at https://andrewmish12.github.io

## How to update
1. Edit `_content.py`. Every project is one block (title, status, sections, honest take).
2. Run `python3 _build.py`. It regenerates every `.html` page.
3. Upload or commit the changed files. GitHub Pages redeploys in about a minute.

Styling lives in `_style.css`. Files starting with `_` aren't served on the live site.

## Rules for this site
- No patient info, hospital client names, or internal SilverStay screenshots, ever.
- No phone number. Contact goes through email and LinkedIn.
